旧衣回收、生活缴费分别规划；具体项目、接入和结算方案需后续研究确认。

1.1 · 家庭生活

旧衣物回收

合作背景：本次会议提供飞蚂蚁合作信息。具体项目、服务接入与结算方式仍需后续方案确认。

1.1.1 为什么做，走哪条经营路线

规划定位 · 家庭服务复访＋合作渠道收入

基于飞蚂蚁合作背景，规划可追踪的旧衣回收服务，探索家庭服务复访。

合作基础来自本次会议；天府通已有App服务入口。[G03] ↗ 预约、取件和后端分拣由飞蚂蚁统筹，天府通负责入口、渠道标识、结果展示与异常受理。

经营主线便民回收吸引使用→完成回收、留下服务记录→自愿订阅下次换季提醒→复访；合同有渠道费时取得收入

规划阶段不预设渠道费及收入金额。后续若衔接商品转化，需另行确认可售商品、分佣与核销回传；用户回收权益不属于天府通收入。

1.1.2 竞品怎么做，取什么经验

对象已核实动作天府通的落实动作
飞蚂蚁预约地址、日期、预估重量；取件、分拣及规则内权益。[F17] ↗[F18] ↗[F19] ↗[F23] ↗使用合作渠道，补齐预约到验收的状态和客服责任。
白鲸鱼上门回收连接权益商城，公开渠道验证和订单查询文档。[F25] ↗[F26] ↗渠道号、服务结果与结算一起谈；积分和奖品分别核算。

由此，产品规划应覆盖预约、履约结果和异常受理，未来以实际服务使用与复访评价价值。

查看回收规则和履约证据

飞蚂蚁：预约、取件和分拣处理由合作方承接

官网提供微信、支付宝小程序及App入口；企业介绍披露旧衣物回收、分拣、二手流通、材料再生及资源化利用。隐私协议列运营主体为上海善衣网络科技有限公司。[F17] ↗[F18] ↗[F20] ↗

整理打包→预约取件→物流收件→分拣验收→规则内奖励 / 再利用

用户获得什么：App Store开发者描述包含有偿回收、环保豆与福利商城。宣传价格上限、免运费及响应时效不直接作为天府通专属渠道承诺。[F19] ↗

预约怎么做：官方公开预约页列地址、联系人、日期与预估重量，城市列表含成都；具体地址可否服务仍要实时确认。权益按当单选择和验收规则发放，商城示例商品不等于自动赠送。[F23] ↗

白鲸鱼：回收连接权益，也提供渠道接入文档

官网介绍预约、免费上门收衣、商城代金券 / 鲸鱼币与绿色商城；页面提供预约记录、积分记录和客服工单入口。相关兑换与覆盖仍按其实际规则。[F25] ↗

预约回收→上门收衣→规则内权益→商城使用→记录 / 客服

渠道能力证据：官方文档目录公开第三方会员验证、网页版接入及按appkey查询订单列表 / 状态等内容。它证明同类平台可以将合作渠道产品化，不代表飞蚂蚁已开放同样接口。[F26] ↗

飞蚂蚁公开规则包含起收重量、超量审核；物流合作方有运输与工厂称重安排。合作渠道须重新确认适用规则，不直接承诺宣传价格、免运和时效。[F21] ↗[F22] ↗

1.1.3 产品规划与合作需确认的事项

用户端先做5件事
  1. 说明回收品类、起收条件及实际服务方。
  2. 专属渠道填写地址、日期和预估重量。
  3. 查看预约、取件、签收、验收、权益状态。
  4. 拒收、失约、奖励争议可统一受理。
  5. 完成后自愿订阅下一次换季提醒。
合作规划需确认6项
  1. 现有合同、成都覆盖及渠道适用规则。
  2. 专属渠道号、预约入口或接入文档。
  3. 服务结果、取消、验收与权益反馈。
  4. 取件、物流、奖励和客服费用责任方。
  5. 有效订单 / 重量、费率、结算周期。
  6. 一组联调样单及异常处理负责人。
合作沟通设想：先跑一批可追踪的成都回收订单。天府通承接预约与服务反馈，飞蚂蚁负责实际履约；以双方核验的有效回收量讨论渠道结算，活动补贴单独列账。

1.1.4 谁负责什么，用户最后得到什么

用户整理、预约、交衣天府通入口、状态、受理、对账飞蚂蚁取件统筹、验收、处理与权益

只有外跳、没有回传时，只报导流点击；具备回传后才统计有效完成与结算。隐私、授权和状态范围按合作约定。[F20] ↗

1.1.5 钱从哪来，流量怎样继续转化

收入 / 回报谁买单、买什么结算与判断
回收渠道费飞蚂蚁若依合同采购有效回收量，支付渠道费用。有效订单或验收重量 × 合同单价，减异常扣减；具体费率待确认。
换季回收运营费品牌、机构采购一场换季回收活动：入口、组织、权益与结果报告。独立项目验收收费；物流、物料和奖励的费用责任分别约定。已有历史合作案例，不代表已签收费。[F24] ↗[G02] ↗
完成后商品转化未来如取得商品合作，用户可自主购买餐饮券、影票或日用品，按约定核对渠道收入。须有具体SKU、净订单、退款和核销。未签商品和佣金时，此项不预设收入。
服务复访用户下次有回收需要再次使用App。以实际使用与后续复访，评价用户经营价值。

1.1.6 规划推进条件与评价方式

  1. 资源研究阶段梳理现有合作范围，研究渠道、履约回传、权益与结算的可行合作方式。
  2. 方案确认后再组织正常履约、取消和验收争议样例验证，确认产品、服务及责任边界。
  3. 项目获批后另行确定实施范围、排期和评价口径，关注服务完成、问题处理、复访与合作收入。

价值评价关注服务是否办完、结果是否可查、用户是否再次使用，以及合作收入和合作方持续意愿。项目排期与具体条款以后续确认为准。

生活缴费：水、电、气

规划提供查账、缴费、入账凭证和提醒服务；实际收费单位、通道、授权和合作条款尚待后续确认。

1.2.1 为什么做，是否靠工具直接赚钱

规划定位 · 便民服务复访＋后续合作转化

承接家庭周期性办事，让用户在缴费完成后仍有记录、凭证和下一期提醒。

可在既有App入口试点。[G03] ↗ 新增缴费仍需逐收费单位确认授权、支付通道和入账回传，现有乘车能力不自动等于缴费已接通。

经营主线便利查账、缴费→入账可查、账期提醒→下一期再使用→已签权益自愿转化

基础缴费的渠道费、营销服务费和商品分佣需后续分别确认。平台价值重点在便民使用、账期复访和自愿的后续商品转化，账单金额不属于平台收入。

1.2.3 产品规划与合作需确认的事项

页面与服务做6步
  1. 选水 / 电 / 气及实际收费单位。
  2. 保存家庭别名与脱敏户号，核对账单。
  3. 展示应缴或预存类型、金额及单位。
  4. 通过获准支付 / 代收通道付款，防重单。
  5. 查询单位入账，展示凭证及发票入口。
  6. 异常处理中提示，自愿订阅下期提醒。
商务分两层对接
  1. 业务层：向实际收费单位或其已授权渠道确认覆盖、户号、账单与销账规则。
  2. 通道层：向现有支付合作团队核对正式代收通道、准入及通道费。
  3. 共同拿到查账、支付、入账、退款、对账样例和响应责任。
  4. 若谈营销预算，与采购方另签权益和服务费合同。
合作沟通设想：可从具备完整查账、入账和退款服务的收费单位研究合作，逐项确认实际覆盖、通道、状态与可能的商业合作方式，形成方案后再安排验证。

1.2.4 把支付成功走到单位入账

用户核户号、确认金额、付款天府通关联订单、查状态、受理支付 / 收费方扣款、入账、退款与凭证

错缴、扣款未入账和退款按责任方处理；处理中保留唯一订单与查询入口，避免重复缴费。

1.2.5 获利点和转化动作分别是什么

路径具体动作 / 谁付钱核算依据
基础工具合作渠道或收费单位只有在合同约定时支付服务费。未确认直接收入待合同确认；缴费额作为业务量单列。
缴费后营销银行 / 品牌采购权益活动，用户缴费后自愿领取，采购方承担约定权益和服务费。存在类似采购模式，仍需具体合同。[G02] ↗项目交付与验收；补贴预算和天府通服务费分开。
缴费后卖券规划可在成功页展示未来获准销售的餐饮套餐券或电影兑换券；用户自主购买后，按合作约定核对交易与佣金。必须先有SKU、适用门店、库存、退改、分佣及回传；缺任一项则不计这条收入。
周期性复访账期提醒带回下一次服务使用。关注实际服务使用和账期复访。

1.2.6 规划推进条件与评价方式

  1. 资源研究阶段研究各收费单位及获准渠道的覆盖、账单类型、入账和售后规则。
  2. 合作方案确认后再设计正常缴费、支付失败、扣款待入账及退款样例，明确相关单位责任。
  3. 实施条件具备后另定范围与排期，按真实账期评估服务完成、提醒使用、复访和合作收入。

价值评价关注办理便利、入账可查、异常闭合、账期复访和后续合作转化；新增收费单位按实际合作条件分别确认。

2.3 · 下班去耍

商圈主题活动：闲暇活动预告与消费转化

规划研究营销运营服务和独立商品转化。具体商圈、活动、门店与商品均为项目示例，尚无合作及启动安排。

2.3.1 广告营销费、卖券佣金，分别怎么赚

规划定位 · 营销服务合作＋商品交易转化

把闲暇活动预告、福利参与和具体商品衔接，探索商圈营销服务与交易合作。

天府通可衔接出行选择与目的地活动；商圈需要提供主题、门店、权益和预算。公交地铁入口与路线能力是产品基础，具体流量和商家增量由试点验证。[G03] ↗

商圈确定预算 / 商品→体验、优惠吸引参与→餐饮套餐券 / 影票兑换券→支付、到店、核销与退单→项目服务费＋独立交易净佣金

固定营销费按专题、分发和运营交付验收；券佣金按独立商品交易结算。同一交付固定费与效果费择一，组合收费要在合同中拆清。领券量和券面值都不作为收入确认依据。

2.3.3 项目示例的合作组合与沟通方向

项目示例｜闲暇活动主题合作包仅说明产品组合，周期、门店、商品和资源均待后续确认
天府通交付
  1. 活动预告与主题内容，说明地点、参加方式及出行。
  2. 按未来授权研究餐饮、观影等商品或权益入口。
  3. 根据实际可用资源，另定传播与触达方案。
  4. 研究关注、报名、领券、支付和核销记录。
  5. 根据合作范围设计效果反馈和服务报告。
商圈与商户提供
  1. 有预算和签约权的采购主体。
  2. 节目、场地、门店及图文使用授权。
  3. 真实可售套餐 / 影票商品、实付价与供货价或佣金。
  4. 库存、时段、使用门槛、有效期与退改。
  5. 核销、净交易、退款账单及现场负责人。
合作沟通设想：可围绕一个闲暇主题交流活动传播、参与服务和商品合作。若对方有营销采购意向，再讨论交付与验收；若适合商品分销，再确认SKU、价格、权益、退改、佣金和回传。当前仅作为规划思路，不预设合作周期和启动时间。
营销服务合作

未来可按专题、约定传播和运营交付讨论采购及验收；广告展示需另行核实资源与计量。

商品分佣合作

未来如取得具体SKU和交易授权，可按可结算净订单或净成交额讨论佣金。

资源互换合作

未来可交流内容、活动参与和权益资源，以用户使用、后续转化及持续合作评价价值。

2.3.4 预算、聚客、卖券和验收怎样串起来

商圈采购预算、主题、组织商户、验收天府通方案、专题、分发、服务与对账商户商品、核销、现场履约和退改

用户获得符合规则的活动体验和商品权益；商圈拿到可验收运营交付，消费效果另以真实交易核对；天府通取得合同收入和可重复合作记录。

2.3.5 三种收入形式与平台价值

收费形式谁付钱，为什么收入如何核算
营销运营服务费商圈 / 品牌购买专题、约定分发、权益组织和复盘。按交付验收确认服务收入；广告展示若单卖，须单独确认资源与计量。
按有效核销效果费采购方购买合同定义的有效结果。有效去重核销×服务单价；不符合、取消及退款剔除，与同一交付固定费互斥。
券销售佣金用户买具体商品，供应方为有效交易付渠道佣金。按合同可结算净成交额×费率，或有效订单单价。券面值、GMV与平台收入分列。

平台价值规划关注营销服务收入、商品交易佣金、用户活动使用与复访，以及商圈合作的持续性。实际收入以未来合同、服务交付和结算为准。

2.3.6 规划推进条件与评价方式

  1. 项目方向研究以商圈和主题活动示例研究用户需求、供给形式及可能的营销 / 商品合作。
  2. 合作方案形成后再确认参与方、内容、商品、授权、验收和结算，届时另行确定范围与排期。
  3. 未来项目评价按实际合作范围观察活动预告使用、参与、商品转化、合作收入和客户续投意愿。

规划原则以合作条件成熟为前提逐步推进；示例中的商圈、门店、商品与活动均不代表已达成合作。
