1.4 业务闭环

服务天府通与合作方各做什么最终交付
旧衣回收天府通承接入口、渠道和受理；飞蚂蚁统筹取件、验收、处理及权益用户取得处理结果；平台取得服务记录及合同结算依据
生活缴费天府通关联订单与结果；支付方扣款，收费单位确认入账用户取得缴费凭证；平台完成差错跟踪和下期提醒

只有外跳、没有回传时，仅统计导流；支付成功不直接等于单位入账。

1.5 落地试点

阶段做什么验收什么
1—30天核对飞蚂蚁合同、渠道规则和缴费通道样例订单、费用与责任清楚
31—60天上线入口、状态、提醒和异常受理用户能办完，问题能跟进
61—90天验证换季 / 账单复访，核算服务投入合同收入、增量复访及净投入

扩展依据：履约稳定、成本可控，并能证明收入或复访改善。排期为资源到位后的建议。

角色负责什么最终获得什么

官方外跳无回传，只计导流；签到与消费核销分开，渠道归因不等于真实增量。

展开交易分支与停办处理
交易分支业务流程平台真正闭合到哪一步订单与售后归属
A 官方跳转活动详情 → 官方预约 / 购票 → 原平台管理订单无回传仅闭合信息导流；可统计点击，不能报成交 / 到场售前提示原渠道负责交易与售后，天府通提供正确入口和信息更新
B 授权票务分销渠道下单 / 锁库存 → 支付 → 凭证 → 核销 / 退款回传 → 净佣金结算闭合可归因交易与结算，需要订单查询、退改及对账能力明确票务履约方；平台统一受理、转负责方跟进，结果可查
C 免费报名 / 商圈券名额 / 券库存 → 唯一凭证 → 现场核销 → 去重报表 → 复访闭合参加或权益使用；消费效果另需商家实际交易回传主办方 / 商户负责现场履约；取消释放名额，核销异常可申诉

停办先停止报名 / 售卖并通知，再按规则退款或释放名额。组合权益分别处理，平台受理后由实际责任方跟进。

2.5 落地试点

阶段做什么验收什么
1—30天建议选1个商圈、3—5家主办方，确认供给和预算内容有人更新，项目可报价
31—60天上线发现、参加方式、出行与核销，跑完一场活动用户能参加，异常能处理
61—90天完成付费项目验收，核对成本与结算项目贡献、履约质量、客户续投意愿
