1.1 · 家庭生活

旧衣物回收

合作方：飞蚂蚁。先跑通预约、取件、结果回传，再判断渠道收入和服务复访是否值得继续投入。

1.1.1 为什么做，走哪条经营路线

业务定位 · 服务复访＋合同渠道收入

以现有飞蚂蚁合作切入，把一次旧衣整理变成一次可完成、可追踪的家庭服务。

合作基础来自本次会议；天府通已有App服务入口。[G03] ↗ 预约、取件和后端分拣由飞蚂蚁统筹，天府通负责入口、渠道标识、结果展示与异常受理。

经营主线便民回收吸引使用→完成回收、留下服务记录→自愿订阅下次换季提醒→复访；合同有渠道费时取得收入

渠道费尚未核实，预算按0。若需要后续卖券转化，须另外拿到可售商品、分佣和核销回传，回收奖励本身不形成天府通收入。

1.1.2 竞品怎么做，取什么经验

对象已核实动作天府通的落实动作
飞蚂蚁预约地址、日期、预估重量；取件、分拣及规则内权益。[F17] ↗[F18] ↗[F19] ↗[F23] ↗使用合作渠道，补齐预约到验收的状态和客服责任。
白鲸鱼上门回收连接权益商城，公开渠道验证和订单查询文档。[F25] ↗[F26] ↗渠道号、服务结果与结算一起谈；积分和奖品分别核算。

由此，首期重点是让用户办完且查得到结果，按真实完单评估服务价值。

查看回收规则和履约证据

飞蚂蚁：预约、取件和分拣处理由合作方承接

官网提供微信、支付宝小程序及App入口；企业介绍披露旧衣物回收、分拣、二手流通、材料再生及资源化利用。隐私协议列运营主体为上海善衣网络科技有限公司。[F17] ↗[F18] ↗[F20] ↗

整理打包→预约取件→物流收件→分拣验收→规则内奖励 / 再利用

用户获得什么：App Store开发者描述包含有偿回收、环保豆与福利商城。宣传价格上限、免运费及响应时效不直接作为天府通专属渠道承诺。[F19] ↗

预约怎么做：官方公开预约页列地址、联系人、日期与预估重量，城市列表含成都；具体地址可否服务仍要实时确认。权益按当单选择和验收规则发放，商城示例商品不等于自动赠送。[F23] ↗

白鲸鱼：回收连接权益，也提供渠道接入文档

官网介绍预约、免费上门收衣、商城代金券 / 鲸鱼币与绿色商城；页面提供预约记录、积分记录和客服工单入口。相关兑换与覆盖仍按其实际规则。[F25] ↗

预约回收→上门收衣→规则内权益→商城使用→记录 / 客服

渠道能力证据：官方文档目录公开第三方会员验证、网页版接入及按appkey查询订单列表 / 状态等内容。它证明同类平台可以将合作渠道产品化，不代表飞蚂蚁已开放同样接口。[F26] ↗

飞蚂蚁公开规则包含起收重量、超量审核；物流合作方有运输与工厂称重安排。合作渠道须重新确认适用规则，不直接承诺宣传价格、免运和时效。[F21] ↗[F22] ↗

1.1.3 第一版做什么，先与飞蚂蚁谈什么

用户端先做5件事
  1. 说明回收品类、起收条件及实际服务方。
  2. 专属渠道填写地址、日期和预估重量。
  3. 查看预约、取件、签收、验收、权益状态。
  4. 拒收、失约、奖励争议可统一受理。
  5. 完成后自愿订阅下一次换季提醒。
首轮合作要拿6项
  1. 现有合同、成都覆盖及渠道适用规则。
  2. 专属渠道号、预约入口或接入文档。
  3. 服务结果、取消、验收与权益反馈。
  4. 取件、物流、奖励和客服成本承担方。
  5. 有效订单 / 重量、费率、结算周期。
  6. 一组联调样单及异常处理负责人。
首谈提案：先跑一批可追踪的成都回收订单。天府通承接预约与服务反馈，飞蚂蚁负责实际履约；以双方核验的有效回收量讨论渠道结算，活动补贴单独列账。

1.1.4 谁负责什么，用户最后得到什么

用户整理、预约、交衣天府通入口、状态、受理、对账飞蚂蚁取件统筹、验收、处理与权益

只有外跳、没有回传时，只报导流点击；具备回传后才统计有效完成与结算。隐私、授权和状态范围按合作约定。[F20] ↗

1.1.5 钱从哪来，流量怎样继续转化

收入 / 回报谁买单、买什么结算与判断
回收渠道费飞蚂蚁若依合同采购有效回收量，支付渠道费用。有效订单或验收重量 × 合同单价，减异常扣减；未确认按0。
换季回收运营费品牌、机构采购一场换季回收活动：入口、组织、权益与结果报告。独立项目验收收费；物流、物料和奖励成本列明。已有历史合作案例，不代表已签收费。[F24] ↗[G02] ↗
完成后商品转化用户自愿购买已签约的餐饮券、影票或日用品；商家按合同支付佣金。须有具体SKU、净订单、退款和核销。未签商品和佣金时，此项收入为0。
服务复访用户下次有回收需要再次使用App。以对照评估复访增量及单位成本，单独作为用户经营价值。

1.1.6 怎么推进，什么结果才扩展

  1. 商务先确认对现有合同逐条确认渠道、成本、结算与售后；拿不到回传，先按导流试点。
  2. 产品跑样单测一次正常履约、一次取消和一次验收争议，验证用户能查最终结果。
  3. 运营开小试点限已核实覆盖地区和预算；按真实完单、投诉、净投入与后续复访复盘。

扩展条件履约稳定、成本在预算内，且合同贡献或增量复访能够证明。用户现金、环保豆和后端材料收入不计天府通收入。

1.2 · 家庭生活

生活缴费：水、电、气

单独作为便民复访业务评估。先确认收费单位和正式通道，再做查账、缴费、入账凭证及下期提醒。

1.2.1 为什么做，是否靠工具直接赚钱

业务定位 · 便民服务留存；直接分佣按合同确认

承接家庭周期性办事，让用户在缴费完成后仍有记录、凭证和下一期提醒。

可在既有App入口试点。[G03] ↗ 新增缴费仍需逐收费单位确认授权、支付通道和入账回传，现有乘车能力不自动等于缴费已接通。

经营主线便利查账、缴费→入账可查、账期提醒→下一期再使用→已签权益自愿转化

基础缴费的直接分佣未核实，按0建预算。若只有缴费工具、没有付费合同，回报应按增量复访评价，不能把账单金额当平台收入。

微信支付绑户号、提醒、查缴、发票等；接入需审核、签约与联调。[F10] ↗[F15] ↗按真实可开通单位上线，支付和入账分开确认。
成都实际收费方供水、燃气各有服务区域与渠道；电力有官方入口。[F11] ↗[F12] ↗[F13] ↗明确单位、户号类型、账期或预存规则，逐项验收。

因此，迁移动机需要来自办理方便、结果清楚和提醒有效，先用试点验证用户是否愿意改用。

1.2.3 第一版做什么，先找谁谈

页面与服务做6步
  1. 选水 / 电 / 气及实际收费单位。
  2. 保存家庭别名与脱敏户号，核对账单。
  3. 展示应缴或预存类型、金额及单位。
  4. 通过获准支付 / 代收通道付款，防重单。
  5. 查询单位入账，展示凭证及发票入口。
  6. 异常处理中提示，自愿订阅下期提醒。
商务分两层对接
  1. 业务层：向实际收费单位或其已授权渠道确认覆盖、户号、账单与销账规则。
  2. 通道层：向现有支付合作团队核对正式代收通道、准入及通道费。
  3. 共同拿到查账、支付、入账、退款、对账样例和响应责任。
  4. 若谈营销预算，与采购方另签权益和服务费合同。
首谈提案：先接一家具备完整查账、入账和退款能力的收费单位，做小范围便民试点；不先承诺全成都覆盖。请分别报价通道成本、状态接口与可能的渠道收入。

1.2.4 把支付成功走到单位入账

用户核户号、确认金额、付款天府通关联订单、查状态、受理支付 / 收费方扣款、入账、退款与凭证

错缴、扣款未入账和退款按责任方处理；处理中保留唯一订单与查询入口，避免重复缴费。

1.2.5 获利点和转化动作分别是什么

路径具体动作 / 谁付钱核算依据
基础工具合作渠道或收费单位只有在合同约定时支付服务费。未确认直接收入＝0；缴费额作为业务量单列。
缴费后营销银行 / 品牌采购权益活动，用户缴费后自愿领取，采购方承担约定权益和服务费。存在类似采购模式，仍需具体合同。[G02] ↗项目交付与验收；补贴预算和天府通服务费分开。
缴费后卖券成功页展示已签约的餐饮套餐券或电影兑换券；用户自主购买，到店核销，商户按净交易付佣金。必须先有SKU、适用门店、库存、退改、分佣及回传；缺任一项则不计这条收入。
周期性复访账期提醒带回下一次服务使用。比较同类对照的服务复访增量和单位投入。

1.2.6 上线与扩展门槛

  1. 先确认一条完整通道选择已核实覆盖单位，验证账单类型、通道费用和销账回传。
  2. 跑完4类样单正常缴费、支付失败、扣款待入账、退款；财务核对三方状态。
  3. 跨一个真实账期复盘看入账成功、差错处理、提醒退订、复访及自担成本，再决定扩单位。

扩展条件查缴稳定、差错可闭合、单位成本可控，并证明合同收入或便民复访价值。每新增一家收费单位重新验收。

2.3 · 下班去耍

商圈主题活动：先签预算与商品，再用福利聚客

首期主推商圈付费的活动运营包，券销售作为独立交易线。先确定采购方和可售SKU，再安排触达、参与和核销。

2.3.1 广告营销费、卖券佣金，分别怎么赚

业务定位 · 营销运营项目为主＋独立交易佣金

让商圈采购可验收的下班消费活动，把福利发放接到实际商品和核销。

天府通可衔接出行选择与目的地活动；商圈需要提供主题、门店、权益和预算。公交地铁入口与路线能力是产品基础，具体流量和商家增量由试点验证。[G03] ↗

商圈确定预算 / 商品→体验、优惠吸引参与→餐饮套餐券 / 影票兑换券→支付、到店、核销与退单→项目服务费＋独立交易净佣金

固定营销费按专题、分发和运营交付验收；券佣金按独立商品交易结算。同一交付固定费与效果费择一，组合收费要在合同中拆清。领券量和券面值都不计收入。

2.3.3 拿什么方案去谈，第一单具体交付什么

首单建议：1个商圈 × 14天 × 3家商户合作确认后的试点建议，非成交合同
天府通交付
  1. 1个下班主题页，讲清活动、门店和去返程。
  2. 3款商品上架，每家商户先做1款。
  3. 计划2轮站内分发，展示位和触达资源先内部确认。
  4. 报名 / 领券 / 支付 / 核销按链路留记录。
  5. 1份交付、净交易、退款与成本复盘。
商圈与商户提供
  1. 有预算和签约权的采购主体。
  2. 节目、场地、门店及图文使用授权。
  3. 真实可售套餐 / 影票商品、实付价与供货价或佣金。
  4. 库存、时段、使用门槛、有效期与退改。
  5. 核销、净交易、退款账单及现场负责人。
首谈开场：我们建议做14天下班消费试点。请先确认是采购活动运营，还是只接受商品分销。前者按交付清单报价验收；后者请给可售SKU、渠道价 / 佣金、库存和回传。拿到这两类资源后，天府通再锁定可用触达和执行预算。
A 有营销预算

签采购主体、服务费、具体资源、验收与付款；固定费或效果费择一。纯广告展示另核可售资源和曝光口径。

B 只有商品分佣

签商品及售后责任，先算每单贡献与盈亏平衡量；用有限入口试售，按真实净订单结算。

C 只愿资源互换

限定为小规模内容 / 聚客试点，明确转化SKU或后续采购评估；没有结果和预算，不扩自担补贴。

2.3.4 预算、聚客、卖券和验收怎样串起来

商圈采购预算、主题、组织商户、验收天府通方案、专题、分发、服务与对账商户商品、核销、现场履约和退改

用户获得符合规则的活动体验和商品权益；商圈拿到可验收运营交付，消费效果另以真实交易核对；天府通取得合同收入和可重复合作记录。

2.3.5 哪种费用值得做，纯卖券要多少量

收费形式谁付钱，为什么收入如何核算
营销运营服务费商圈 / 品牌购买专题、约定分发、权益组织和复盘。按交付验收确认服务收入；广告展示若单卖，须单独确认资源与计量。
按有效核销效果费采购方购买合同定义的有效结果。有效去重核销×服务单价；不符合、取消及退款剔除，与同一交付固定费互斥。
券销售佣金用户买具体商品，供应方为有效交易付渠道佣金。按合同可结算净成交额×费率，或有效订单单价。券面值、GMV与平台收入分列。

  1. 商务先约两家P1先向大悦城、悠方市场 / 会员团队递首单清单；确认采购预算或商品分销意向，太古里列品牌项目储备。
