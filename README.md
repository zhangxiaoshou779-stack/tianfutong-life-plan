# 天府通生活创新方案

当前为五项业务落地版 v6。先完整说明家庭生活中的旧衣物回收、生活缴费，再逐项说明下班去耍中的圈子活动、联展与看展专题、商圈主题活动。

每项业务分别包括：机会与经营路线、竞品与启示、具体产品与谈判资源、角色闭环、收入和转化证据、首期执行与验收。具体列出成都候选主办方、展览和商圈，区分已公开事实、待谈条件与拟议方案；未进行对外接洽或真实交易。
